# 저장소 파악

## 먼저 확인할 것

- 요청의 목표, 기대 산출물과 완료 조건을 확인합니다.
- `git status --short --branch`로 현재 브랜치와 작업 트리를 확인합니다. 이전 작업과 이어지는 경우 최근 커밋도 살핍니다.

## 탐색 순서

1. [저장소 구조](../../../docs/architecture/repo-structure.md)에서 파일의 역할을 파악합니다. 화면 작업은 [주요 화면](../../../docs/architecture/app-structure.md#주요-화면)과 실제 라우트에서 대상 URL의 진입점을 찾습니다.
2. 페이지와 상위 레이아웃에서 호출하는 기능 컴포넌트, 훅, API를 순서대로 확인합니다. 유사한 동작이 이미 있으면 위치와 호출부를 파악합니다.
3. [스킬 선택 표](../../../AGENTS.md#스킬-선택)에서 필요한 문서를 고릅니다. 실행 환경이나 스크립트를 변경하는 작업은 [로컬 개발](../../../docs/workflows/local-development.md)과 `package.json`을 대조합니다.

## 작업 시작점

관련 기능과 현재 구현, 영향받는 사용처와 검증 후보를 정리합니다. 작은 변경은 바로 구현할 수 있을 만큼만 확인합니다.
