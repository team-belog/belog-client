# 프론트엔드 검증

## 참고 문서

- `docs/workflows/verification.md`
- `docs/agent/maintenance.md`

## 검증 범위 선택

검증 문서의 표에서 변경에 맞는 명령과 확인 항목을 선택합니다.
문서와 하네스는 새 파일을 포함해 공백, 링크와 참조 경로를 확인합니다.
스킬 변경은 하네스 유지보수 문서의 이름과 메타데이터 검사도 적용합니다.

## 검사 실행

- 타입 검사는 검증 가이드의 순서대로 Next.js 라우트 타입을 생성한 뒤 실행합니다. 빌드와 브라우저
  확인 여부는 검증 표에서 확인합니다.
- 정적 검사 경고에서 앱 소스와 PWA 생성물을 구분합니다. 실패가 발생하면 어떤 단계에서 어떤 조건으로
  발생했는지 확인합니다.
- 앱 동작 확인은 바뀐 사용자 흐름을 우선합니다. 인증, 업로드, 푸시처럼 환경이 필요한 변경은 재현한
  경로와 사용한 설정의 종류를 기록합니다.

## 결과 정리

실행한 명령과 결과를 적습니다. 확인 범위 밖에 남은 항목은 이유를 함께 기록합니다. 오류를 고쳤다면
해당 검사와 영향을 받는 검사를 다시 실행합니다.
